# 3d-room
Group Members: Savannah Lee, Samantha Oh, Nitya Shankar, and Jayden Salman

## About

3d-room is a web application for creating and editing 3D room layouts from uploaded photos or floor plans. We are planning a home page, an upload page, an interactive 3D editor, and a library where users can save their spaces.

## Technologies

We are exploring Three.js and React Three Fiber for interactive 3D graphics in the browser, with React for the user interface. We will use GitHub for version control and project planning.
